# Bloque M3 · Portal del tutor

Rama: `feature/sprint4-tutor` (desde `main` actualizado, con los bloques M1 y M2). PR a `main` sin unir.

## Reglas

- Seguir `CLAUDE.md` y `docs/ESTANDAR-PROGRAMACION.md` en todo; responder en español.
- Decisiones del equipo:
  - El tutor **no** es un rol de inicio de sesión: es un docente. Si es tutor o cotutor de una sección del año en
    curso, su portal de docente muestra el menú «Mi tutoría». El servidor lo valida en cada ruta: 403 si no es tutor
    ni cotutor de esa sección.
  - La asistencia del tutor es **sobre las clases existentes** (`sesion_clase` y `asistencia_estudiante`). No se crea
    una asistencia diaria aparte.
- Al terminar cada fase: `npm run typecheck` y las pruebas, commit Conventional en español, `git push` y marcar la
  fase aquí. Si una conversación se queda sin contexto, otra continúa desde este archivo.
- Solo datos ficticios (RNF14). No ejecutar `db:reset` ni `db:migrate` contra Neon. Verificar con una base temporal,
  nunca con `kubo_dev`.
